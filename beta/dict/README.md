# Dictionary data

English–German dictionary files of the Reading Companion, one file per first letter.

Source: [WikDict](https://www.wikdict.com/) (en-de), which is derived from [Wiktionary](https://en.wiktionary.org/) via DBnary.
Licence: [Creative Commons Attribution-ShareAlike 3.0](https://creativecommons.org/licenses/by-sa/3.0/). The files in this folder are an adapted
extract (shortened, re-ordered, with a list of inflected forms added) and are available under the same licence.

Rebuild with `tools/build_dict.py <en-de.sqlite3> <target folder>`.
